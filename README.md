# 🌿 smart-irrigation-system-iot

Bu portal, akıllı sulama sisteminin dijital rehberidir. Projenin teknik dökümantasyonunu sunarken, bitki türlerine göre ideal nem sınırlarını içeren kapsamlı bir veri rehberi barındırır. Kullanıcıların sistem hakkında bilgi almasını ve iletişim formu üzerinden geliştiriciyle güvenli bir şekilde etkileşime geçmesini sağlayan bir arayüzdür.

## 💻 Web Portalı Özellikleri
* **Dijital Bitki Rehberi:** Popüler bitki türlerinin sağlıklı gelişimi için gerekli olan ideal nem aralıklarını listeleyen dinamik bir veri tabanı sunar.
* **Teknik Dökümantasyon Paneli:** Akıllı sulama sisteminin çalışma prensipleri ve teknik bileşenleri hakkında detaylı bilgi içerir.
* **İletişim ve Destek:** PHP tabanlı güvenli bir form aracılığıyla kullanıcıların geliştiriciye doğrudan ulaşmasını sağlar.
* **Kullanıcı Dostu Arayüz:** Modern tasarım standartlarına uygun, tüm cihazlarda (mobil/masaüstü) sorunsuz çalışan duyarlı bir yapıya sahiptir.

## 🛠️ Kullanılan Teknolojiler
* **Backend:** PHP
* **Frontend:** Bootstrap / CSS / HTML
* **Sunucu Yönetimi:** XAMPP (Yerel Geliştirme)
* **Versiyon Kontrol:** GitHub

## 📂 Proje Yapısı
* `/assets`: Görseller ve stil dosyaları (CSS/JS).
* `/includes`: PHP 'include' dosyaları (Header/Footer/Database).
* `index.php`: Portala giriş ve ana karşılama sayfası.
* `plants.php`: Bitki nem rehberinin listelendiği sayfa.
* `contact.php`: İletişim formu ve mail gönderim modülü.
